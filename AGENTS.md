# aegis-sdd — Aegis SDD

Before doing anything here, read `.aegis/generated/rules.md` — the project's compiled agent
rules, which are authoritative for every runner. Then run `aegis next` for the current step.

This repository is the framework, so the `aegis` command comes from this checkout: run
`./install.sh` once if it is missing. `.aegis/generated/index/INDEX.md` is the index to read
before searching the tree.
